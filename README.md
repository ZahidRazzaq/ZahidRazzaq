## Research focus

- **Video understanding & action recognition** — fine-grained procedural assembly/disassembly activities.
- **Multimodal learning** — RGB–Depth fusion and gaze-aware modelling using early, intermediate, late, and hybrid fusion strategies.
- **Egocentric sensing** — Meta Project Aria workflows for RGB/gaze extraction, multimodal recording, temporal annotation, and timestamp mapping.
- **Human–robot interaction** — human activity understanding for HRC and earlier EEG-based shared control for a simulated brain-controlled mobile robot.

## Selected research projects

### Multimodal procedural video understanding
Built a unified PyTorch benchmark for **RGB–Depth action recognition** using Video Swin Transformer/Swin3D and X3D, comparing recognition performance with latency, GFLOPs, and parameter count.

### Gaze-aware action recognition
Evaluated **RGB+gaze integration, explicit gaze markers, gaze-guided foveation, and feature-level modulation**. The best controlled input-level gaze configuration improved the RGB baseline by approximately **1.5 percentage points**.

### Project Aria multimodal dataset workflow
Designed and conducted an assembly/disassembly recording study with approximately **24 participants** using **Meta Project Aria** and two fixed-view cameras. Developed a reusable fine-grained temporal annotation and timestamp-mapping workflow.

### EEG-based brain–robot shared control
Acquired and processed EEG data, trained SVM intention classifiers, and developed fuzzy / self-learning neuro-fuzzy shared-control methods in **MATLAB/Simulink**.
